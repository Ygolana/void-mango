Noctalia is provided by third-party repository [`UniversalRepository`](https://universalrepo.pages.dev)

**Step 1**: Install repository

```bash
echo 'repository=https://universalrepo.pages.dev/void' | sudo tee /etc/xbps.d/10-universalrepository.conf
```

**Step 2**: Sync and import the signkey

```bash
sudo xbps-install -S
```

**Step 3**: Install noctalia

```bash
sudo xbps-install -S noctalia
```

:::note
If your noctalia fails on run, install sdbus from UniversalRepository because its up-to-update
